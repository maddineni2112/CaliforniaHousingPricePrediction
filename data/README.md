# Data statement

The project uses California housing and Redfin-style housing records as documented in the final report. Raw housing records are excluded because they are large external data and may have provider-specific terms. Model artifacts are also excluded from this portfolio repository.

Obtain the source data from the documented provider, retain the response and predictor schema described in the report, and update the pipeline input path. The application can then regenerate preprocessing, evaluation outputs, and local serving artifacts.
