# California Housing Valuation Intelligence

**Timeline:** December 2024  
**Category:** Main project

This project builds an end-to-end housing valuation workflow for California housing data. It covers cleaning, scaling, polynomial features, recursive feature elimination, model comparison, persisted inference artifacts, and lightweight Flask/Streamlit serving interfaces.

## Stack

Python, Pandas, NumPy, SciPy, scikit-learn, XGBoost, Joblib, Streamlit, Flask, REST APIs, StandardScaler, polynomial features, RFE, and Seaborn.

## Repository contents

- `src/` — pipeline and serving modules.
- `reports/` — final project report.
- `data/README.md` — Redfin/California data provenance and excluded-data instructions.
